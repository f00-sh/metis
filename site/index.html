Metis

An empty Common Lisp cognitive runtime. Intelligence arrives as sealed dual-facet symbols you load and unload. Residual freeform uses an in-process house chat spine — not a kitchen-sink model, not an external API mind.

  • pure CL neural train
  • reason-act compose
  • house-chat spine
  • open / private sealed
  • MIT

Symbols

Authors train a source kit, seal it (opaque body + hash + signature), publish free. Math and language are dual-facet; other domains default to knowledge. Model packages can condition the house chat spine (adapters / weights metadata). 

./bin/metis symbol train knowledge/source-kits/calculus
./bin/metis symbol build knowledge/source-kits/calculus
./bin/metis symbol load knowledge/sealed/calculus

Dual-facet law

Math — Knowledge (explain) + Process (compute). Unload removes both.

Language — Use (speak/read) + About (metalanguage).

Domains — Knowledge by default.

Freeform pipeline

chitchat → reason-act → process math → extractive → about-knowledge → house-chat

Product freeform never uses external LLM APIs as the answer mind. Tools (prove/bind, math engines, attachments) remain first-class sieves.

Install

# curl | bash (recommended)
curl -fsSL https://metis.f00.sh/install.sh | bash
# pin: METIS_VERSION=4.5.0

# Homebrew
brew install f00-sh/tap/metis

# AUR-style
# packaging/aur or github.com/f00-sh/aur-metis

# from source
git clone https://github.com/f00-sh/metis.git && cd metis
./bin/metis version && ./bin/metis
